# 📊 Excel Report Generator

An automated data analysis and reporting application built using Python and Streamlit. The application allows users to upload CSV datasets, clean and analyse the data, generate visualisations, and export the results into a structured Excel report.

## 🎯 Objective

The objective of this project is to automate the process of analysing CSV data and generating an Excel-based report containing important statistics, sales analysis, and visualisations.

## ✨ Features

- Upload CSV datasets
- Automatic data cleaning
- Remove duplicate and empty rows
- Calculate total sales
- Calculate average sales
- Display summary statistics
- Analyse sales by category
- Analyse sales by region
- Identify top-performing products
- Generate visualisations using Matplotlib
- Generate formatted Excel reports
- Download the generated Excel report

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- OpenPyXL
- Streamlit
